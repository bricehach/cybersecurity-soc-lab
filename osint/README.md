# Recherche OSINT

Ce dossier rassemble des supports méthodologiques de recherche à partir de sources ouvertes. Le cours principal présente Google dorking, les opérateurs documentés, les limites de l’indexation, la vérification des sources et les usages dans d’autres domaines.

Le support est destiné à un public de deuxième année en cybersécurité et comprend des ateliers pratiques, des corrigés et une grille d’évaluation.
